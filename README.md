# Buzdolabı Işığı Ontolojisi

**Ulusal Soğutma Felsefesi Enstitüsü — Resmî Yazılım**

Buzdolabının kapağını kapattığınız anda içerideki ışık *gerçekten* sönüyor mu?
Yoksa evren, siz bakmadığınız için o fotonları geçici olarak işsiz mi bırakıyor?

Bu soru 1923'ten beri cevaplanmamıştır. Cevaplamayacağız. Sadece *tutanak* tutacağız.

## Ne yapar?

`ontoloji.py` çalıştığında:

1. Kapıyı açar (hayali).
2. Işığı gözlemler (hayali).
3. Kapıyı kapatır (yine hayali).
4. Schrödinger'in yoğurt kabının kapağını açmadan ışığın varlık durumunu yargılar.
5. Size resmî bir karar tebliğ eder.

Hiçbir şey ısınmaz. Hiçbir şey soğumaz. Sadece vicdanınız milimetrik ölçülür.

## Kurulum

```bash
python3 ontoloji.py
```

Bağımlılık: Python 3. Varlık. Biraz da utanc.

## Kullanım

Program soracak:
- Kapı açık mı?
- Içeride yoğurt var mı?
- Sen gerçekten bakıyor musun yoksa sadece meraktan mı soruyorsun?

Cevaplarınız bilimsel olarak işlenmez. Duygusal olarak işlenir.
